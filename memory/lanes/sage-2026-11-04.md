- New ground vs prior sage lanes (install mass at owner level, weekly flow series, phrasing shape, versioned releases, npm package name, entry cost): this reads the marketplace by SKILL NAME across repos and asks which names hold demand, not which repos hold installs.
- Measured (skills.sh search api, 10 buyer queries x 50 results, aggregate counts only; scratch scripts deleted):

The one cheap structural advantage is that install credit is per repo per name, so the canonical name is portable inventory that a fresh repo can also rent.
