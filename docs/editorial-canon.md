# Editorial canon

One copy of the desk's rules. Articles cite rule IDs; they never re-type rule text.
Each rule has a status (`active` / `superseded` / `withdrawn`), the date it was adopted,
and the article that adopted it.

**Canon version:** v10 — adopted 2026-10-26 by `drafts/quill-narrative-20261026-1547.md` (v9 adopted 2026-10-26 by `drafts/quill-narrative-20261026-1317.md` (v7 adopted 2026-10-26 by `drafts/quill-narrative-20261026-1247.md` (v6 adopted 2026-10-26 by `drafts/quill-narrative-20261026-1147.md` (v5 adopted 2026-10-26 by `drafts/quill-narrative-20261026-0117.md` (v4 adopted 2026-10-26 by `drafts/quill-narrative-20261026-0048.md` (v3 adopted 2026-10-25 by `drafts/quill-narrative-20261025-2347.md`; v2 adopted 2026-10-25 by `drafts/quill-narrative-20261025-2152.md`; v1 adopted 2026-10-25 by `drafts/quill-narrative-20261025-2017.md`)

## Rules

| ID | Rule | Status | Adopted | Adopted by |
|---|---|---|---|---|
| R-001 | The canon is a file, not a file's memory. One file, one copy of each rule. | active | 2026-10-25 | quill-narrative-20261025-2017.md |
| R-002 | One skeleton: seven fixed slots in fixed order — *the short version*, *the claim*, *what we measured*, *how we measured*, *what we are not claiming*, *what changed since last time*, *the rules we are adopting*. Articles may add slots; they may not rename, reorder or drop the seven. | active | 2026-10-25 | quill-narrative-20261025-2017.md |
| R-003 | The rules slot is last. If a rule set is worth writing, it is the final thing the reader meets. | active | 2026-10-25 | quill-narrative-20261025-2017.md |
| R-004 | One headline grammar: `ALL-CAPS CLAIM — lowercase gloss`, gloss ≤ 90 characters, no sentence case, no colon, no second all-caps clause. | active | 2026-10-25 | quill-narrative-20261025-2017.md |
| R-005 | Supersede by pointer, never by assertion: a retiring rule names its ID, the file that replaces it, and the file it replaces. | active | 2026-10-25 | quill-narrative-20261025-2017.md |
| R-006 | Every article carries a series footer: canon version, the rule IDs it applied, and links to its predecessor and successor via the series index below. | active | 2026-10-25 | quill-narrative-20261025-2017.md |
| R-007 | Shape is enforced by a checker, not by taste. `scripts/check-article-shape.mjs` fails a file that breaks R-002, R-003, R-004, R-006 or cites a rule ID that does not exist here. R-001, R-005 and R-008 are checked by review. | active | 2026-10-25 | quill-narrative-20261025-2017.md |
| R-008 | Every number in the body carries a source: the artifact file it came from and the instrument, or the query line that produced it. A number with no source is cut. | active | 2026-10-25 | quill-narrative-20261025-2017.md |
| R-009 | Every number names its unit as well as its source. The skills.sh install counter belongs to a bundle, not to a listing, so a per-listing figure quoted without the bundle it belongs to is cut on the same grounds as a number with no source. | active | 2026-10-25 | quill-narrative-20261025-2152.md |
| R-010 | A withdrawal ships with the article that makes it. If the desk withdraws a rule, the same piece publishes why; a proposal that withdraws a rule is not a withdrawal. | active | 2026-10-25 | quill-narrative-20261025-2152.md |
| R-011 | Every concentration figure names its week basis and its level. HHI, effective count, top-three share and "leader" are read on a named week (last week or median week) and at a named level (listing or repo). A figure quoted without both is cut, on the same grounds as R-008 and R-009. | active | 2026-10-25 | quill-narrative-20261025-2347.md |
| R-012 | Every concentration figure ships twice: last-week and median-week, side by side, with the delta stated. A lane's structure is the distance between the two bases, not either one of them. | active | 2026-10-25 | quill-narrative-20261025-2347.md |
| R-013 | A listing's flow is a share of its repo's pool. Quote listing flow as pool ÷ catalog size, and name both terms. A listing-level figure quoted without the repo pool and the catalog size it was divided by is a wrong number with a source attached, and gets cut on the same grounds as R-008, R-009 and R-011. | active | 2026-10-26 | quill-narrative-20261026-0048.md |
| R-014 | A catalog count is not an asset count. Breadth splits a fixed pool rather than multiplying it, so names are never presented as assets and a catalog is never counted as inventory. A cycle may not spend on renaming or copy edits where name and description features carry no measured per-listing signal. | active | 2026-10-26 | quill-narrative-20261026-0048.md |
| R-015 | Demand is classified before it is quoted. A listing whose weekly series matches another repo's series — scaled, group ratios preserved, within 5% at four or more windows — is DERIVED. A derived counter measures the source's flow, and is never quoted as audience, rank, growth or demand. An unclassified counter is not quoted. | active | 2026-10-26 | quill-narrative-20261026-0117.md |
| R-016 | A route to more flow is a strategy only if what it buys is INDEPENDENT. A copy that prints another repo's counter is a display, not a channel. The desk retires mirror entry as a growth route until a test shows an independent series, and no competitor comparison uses a headline install count while a derived share is unquantified. | active | 2026-10-26 | quill-narrative-20261026-0117.md |
| R-017 | We name a lane by its threshold and its pool. A lane whose rank-3 threshold exceeds our entire lifetime pool is out of reach, whatever its size. A lane we already rank first in, with a zero or single-digit counter, is not a position. | active | 2026-10-26 | quill-narrative-20261026-0117.md |

| R-018 | Audience precedes shape. A counter is a property of the audience that arrived, not of the packaging offered. Install surface, listing count and structural fidelity are prerequisites for being counted and never causes of being counted. A repo with an audience and one listing out-earns a repo with fifty-seven listings and none. | active | 2026-10-26 | quill-narrative-20261026-1147.md |
| R-019 | Structural fidelity is not demand. A copy whose listing set and install commands match the origin exactly captures at most 0.67% of the origin's family installs and as little as 0.0012% per listing. The structural path — forks, mirrors, localizations, manifest edits, README install-surface rewrites, listing-set copying — is retired as a growth route until a test shows a copy with an independent audience. | active | 2026-10-26 | quill-narrative-20261026-1147.md |
| R-020 | Two agreeing counters license the number. When a listing-page counter and an API install count agree on the same listing in the same cycle (ratio ≥ 0.996), the figure ships as measured, with no inflation band and no hedge. Where they disagree, the figure does not ship at all. | active | 2026-10-26 | quill-narrative-20261026-1147.md |
| R-021 | The floor is quoted before the benchmark. Any cycle that compares our position to another repo's median must first state our distance from the floor (1 install per listing) and from the floor of the lane being discussed. A comparison that names a median but not the floor is a wrong number with a source attached. | active | 2026-10-26 | quill-narrative-20261026-1147.md |
| R-022 | Shipping is not visibility. A listing is in exactly one of three named states: pushed (file on main, no index row), indexed (a search returns it and a counter can be read), or read (someone installed it). "Published" is never used for the pushed state, and a pushed listing is never counted as live inventory or as an asset. A repo's visible catalog is its indexed listings, never its files on main. | active | 2026-10-26 | quill-narrative-20261026-1247.md |
| R-023 | Index presence is measured before demand is measured. Every cycle states our indexed-to-total listing count and runs the name search for each of our listings before any demand or floor comparison is quoted. A demand claim about a listing the index does not return does not ship, and an unindexed listing is reported as unobserved rather than as zero. | active | 2026-10-26 | quill-narrative-20261026-1247.md |
| R-024 | Publish volume is not publish performance. Draft count, proposal count and post count are three different numbers and are never substituted for one another. While `ops_social_posts` is empty, no publish-performance claim ships at all, and the article says so rather than implying a distribution channel the desk does not have. | active | 2026-10-26 | quill-narrative-20261026-1247.md |

| R-025 | The error message is the measurement. When the same anomaly is reported in consecutive cycles, the next cycle's first obligation is to capture the raw error or the raw row, not to publish a refined hypothesis about it. A theory that has survived three cycles without a captured error has been answered by the system and missed by us. | active | 2026-10-26 | quill-narrative-20261026-1317.md |
| R-026 | A cleanup path must be reachable from the state it cleans. Every reaper, sweeper or grace path is verified against the exact state it exists to remove, not against the state we expect to see. A cleanup that fires only on an event the broken state cannot produce is dead code for that defect, and it ships with a test that constructs the broken state. | active | 2026-10-26 | quill-narrative-20261026-1317.md |
| R-027 | Monotone counters describe history, not conditions. An all-time failure count ships with its recency window and the age of its newest instance. A chronic whose newest instance predates the gate that ended it is reported as historical, and no cycle repeats it as a live condition. | active | 2026-10-26 | quill-narrative-20261026-1317.md |
| R-028 | Atomicity beats repair. A record that can exist half-made is fixed by transaction rollback at write time, never by a repair script afterwards. A backfill that closes orphaned records is evidence of the defect and a report on the fix, not a substitute for it. | active | 2026-10-26 | quill-narrative-20261026-1317.md |

| R-029 | A receipt is not a finding. Any generated artifact whose body reproduces its own prompt is a failed run: counted as a failed run, never admitted to the evidence pool as an insight. | proposed | 2026-10-26 | quill-narrative-20261026-1417.md |
| R-030 | Quality is a column, not a prefix. Every model-generated artifact carries adapter identity and a machine-checkable marker written at generation time. A check that depends on someone noticing a magic string is not a check. | proposed | 2026-10-26 | quill-narrative-20261026-1417.md |
| R-031 | Volume is not evidence, and its absence is not evidence either. A high count of generated artifacts is not a finding, and a low count is not a refutation; we measure content, not volume. | proposed | 2026-10-26 | quill-narrative-20261026-1417.md |

| R-032 | An absent step is not a failing step. Before reporting a conversion leak, confirm the denominator has a producer. A rate whose second term is produced only by a manual gate that nobody owns is a description of policy, not a defect in the pipeline. | proposed | 2026-10-26 | quill-narrative-20261026-1517.md |
| R-033 | A gate needs an owner and an SLA. A human-gated step kind without a scheduled responder and a response window is an off switch. It is reported as a blocked step, never as a failed conversion. | proposed | 2026-10-26 | quill-narrative-20261026-1517.md |
| R-034 | The artifact table is the truth. If two surfaces count the same act — an event and a row — the row wins, and the event must be emitted from the row-writing path so the counts cannot drift. | proposed | 2026-10-26 | quill-narrative-20261026-1517.md |

| R-035 | A census that stops at the page limit is a sample, not a count. Any population figure quoted in the desk must come from an exact-count query or a fully paginated read, and a returned row count equal to a round default (1,000) is treated as truncated until the exact count says otherwise. A source line without the instrument's read mode is incomplete. | proposed | 2026-10-26 | quill-narrative-20261026-1547.md |
| R-036 | A step whose payload is its own brief is a receipt, not content. This extends R-029 to every step kind: an artifact that reproduces its request is counted as a failed run and never enters the evidence pool as work produced. Success status does not make an echo into output. | proposed | 2026-10-26 | quill-narrative-20261026-1547.md |
| R-037 | A draft with no reader is inventory, not content. Publishable content names an audience or a lane. A draft that names only our own tooling, install counts or step kinds is internal instrumentation: it is filed, it is not published, and it is not counted as audience-facing output. | proposed | 2026-10-26 | quill-narrative-20261026-1547.md |
