# Assert, do not argue

192 live drafts, ten days: only 8.8 pct of 7553 sentences carry a causal or contrast connective, median 3 per draft, 59 pct never say because. But 98 pct use subheads and 71 pct use bullets, so the layout promises analysis while the sentences never bind one finding to the next.

Rule: end every finding block with one link clause: because, so, or which means.
